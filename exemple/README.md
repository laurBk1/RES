# Exemple de stil

Pune aici clipurile de referință (Shorts, Reels, TikTok) al căror stil vrei să-l copiem: subtitrări, culori, ritm, motion graphics.

- Câte un fișier `.mp4` pentru fiecare exemplu, de ex. `exemplu-01.mp4` (clipurile nu se urcă pe GitHub, doar analiza lor).
- Opțional, un fișier `exemplu-01.md` cu ce îți place la el („subtitrările galbene”, „zoom-urile rapide”, „cardurile cu liste”).

Agentul analizează fiecare clip (cadre-cheie, poziția și mărimea subtitrărilor, cât de des se schimbă cadrul) și salvează stilul în `style.json`. Copiem doar aspectul și ritmul, nu și textul sau filmările.
